# 💰 Personal Finance Tracker (Simplified)

A simple, fast web application for tracking personal finances with visual analytics. Built with HTML, CSS, and JavaScript - works directly in your browser with support for Indian Rupees (₹).

## Features

### 📊 Quick Dashboard

- **Total Balance**: Your net balance (income - expenses)
- **Total Income**: All income combined
- **Total Expenses**: All expenses combined
- **Savings Rate**: Percentage of income saved

### 💳 Simple Transaction Management

- Add income or expense transactions
- Categorize transactions
- Filter by income or expense
- View all recent transactions
- Delete transactions
- Automatic data saving to browser

### 📈 Visual Analytics

- **Expense Pie Chart**: See where your money goes by category
- **Monthly Bar Chart**: Compare income vs expenses month-by-month
- **Category Summary**: Quick breakdown of spending

### 🎯 Categories

**Income:** Salary, Bonus, Other

**Expenses:** Food, Transport, Shopping, Entertainment, Bills, Other

## Getting Started

### Installation

1. Clone or download the project files
2. Ensure you have the following files:
   - `index.html`
   - `styles.css`
   - `script.js`

### Usage

1. Open `index.html` in your browser
2. Fill in the form:
   - **Description**: What's this transaction for?
   - **Amount**: How much (in ₹)?
   - **Type**: Income or Expense?
   - **Category**: Pick from the dropdown
   - **Date**: When did it happen?
3. Click "Add Transaction"
4. View all your transactions in the list below
5. Check the charts to see your spending patterns
6. Everything is saved automatically!

## How It Works

- **Add Transactions**: Simple form to record income and expenses
- **View Dashboard**: See your total balance, income, expenses, and savings rate at a glance
- **Track with Charts**: Pie chart shows where you spend, bar chart compares months
- **Category Breakdown**: See exactly how much you spend in each category
- **Auto-Save**: Everything is saved to your browser automatically

## Tips

- Update transactions as you go for accurate tracking
- Use the same category names for similar expenses
- Check the pie chart weekly to understand your spending
- Compare months with the bar chart to see trends
